# Airfoil-Generator
A machine learning-powered engine for airfoil selection and generation using data from https://airfoiltools.com/.

# Download Data
You can download the required dataset by running "scraper.py".

# Dataset 
The dataset includes airfoil_graphs.csv, which contains the performance data for all profiles, and airfoil_profiles.json, which contains the shape data for each profile.

# Web-İnter-Face
The web interface allows you to test the profile translator and visualize every profile stored in the database. 

> **Note:** Make sure to run `server.py` to enable profile visualization.
